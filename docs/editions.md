# Editions / 版本范围

[English overview](../README.md) · [中文介绍](../README.zh-CN.md)

Confirmed scope: 7 October 2026. Basic stays free long term. Its separate package and edition separation are still being prepared; this table describes the confirmed design, rather than a publicly available package.

范围确认日期：2026 年 10 月 7 日。Basic 长期免费，独立包与版本隔离仍在准备中；下表说明已确认的版本设计，公开安装包尚未提供。

## Basic: nine pages / 九个页面

| Page / 页面 | Confirmed free scope / 已确认免费范围 |
| --- | --- |
| Dashboard / 工作台 | Market summaries and workspace components; account, trading, bot and performance summaries use Testnet. / 市场摘要与工作台组件；账户、交易、机器人和收益摘要限 Testnet。 |
| Performance / 收益分析 | Testnet ledger metrics, curves, details and attribution, retaining missing or unsettled states. / Testnet 账本指标、曲线、明细与归属说明，保留缺失及未结算状态。 |
| AI / AI | General questions and assistance for free modules, using your provider key; model quotas are separate. / 普通问答及免费模块辅助，使用用户自备提供方 Key，模型额度另计。 |
| Market scanner / 市场扫描 | Basic scanning, filters, sorting, presets and source freshness. / 基础扫描、筛选、排序、预设及来源与时效说明。 |
| Market monitor / 异动监控 | Change and volatility thresholds, watch lists and refresh. / 涨跌与波动阈值、监控列表及刷新。 |
| Factor lab / 因子实验室 | Formulas and templates, statistical experiments, comparisons, candidate saving, factor return backtests, reports and exports. / 公式与模板、统计实验、结果比较、候选保存、因子收益回测、报告与导出。 |
| Testnet / Testnet | Manual trading and automated bots on supported products, with the required strategy setup and trading controls. / 受支持产品的人工交易与自动机器人，保留必要策略配置及交易控制。 |
| Trade management / 交易管理 | Testnet orders, fills, local execution records, cancellation, reconciliation and recovery. / Testnet 委托、成交、本地执行记录、撤单、核对及恢复。 |
| Settings / 设置 | Appearance, language, exchange and AI configuration, Testnet bot and risk settings, logs, storage, backup and recovery, version information. / 外观、语言、交易所与 AI 配置、Testnet 机器人与风控、日志、存储、备份恢复及版本信息。 |

All Basic account access, trading, bots and performance data are limited to Testnet. Public market data is handled separately and does not open Mainnet account access. Necessary credential protection, risk controls, order protection, reconciliation, settlement, exports and recovery remain part of the free workflow.

Basic 的账户访问、交易、机器人和收益数据统一限于 Testnet。公开行情另行处理，不开放 Mainnet 账户访问。必要凭据保护、风控、订单保护、对账、结算、导出与恢复属于免费流程。

Testnet bots require strategy selection, parameters, a saved version and explicit enablement and start. This necessary configuration belongs in Basic; the full strategy library and strategy-run pages belong to the planned paid scope. A research candidate does not automatically become an execution strategy.

Testnet 机器人需要选择策略、配置参数、保存版本，并明确启用和启动。这些必要配置纳入 Basic；完整策略库与策略运行页面属于计划付费范围。研究候选不会自动成为执行策略。

## Full: planned paid scope / 计划付费范围

- Mainnet account access, manual trading and automated trading on supported products. / 受支持产品的 Mainnet 账户访问、人工与自动交易。
- Full market charts, watchlists and market analysis. / 完整市场图表、自选市场与市场分析。
- Research centre, general strategy library, one-click strategy backtests and parameter optimization. / 研究中心、通用策略库、策略一键回测与参数优化。
- General backtest analysis, strategy diagnostics, independent strategy runs, review centre and other user features outside Basic. / 通用回测分析、策略诊断、独立策略运行、复盘中心及未纳入 Basic 的其他用户功能。

Full pricing, billing model, payment, licence issuance and activation remain pending. Payment does not establish support for an otherwise unsupported or unverified product. AI providers, enhanced data and external notifications may require separate accounts, keys, quotas and fees.

Full 的价格、收费模式、付款、许可签发与激活仍待确定。付费不代表原本不支持或未验证的产品已可使用。AI 提供方、增强数据及外部通知可能需要独立账户、Key、额度与费用。

## Platform and release status / 平台与发行状态

The existing local candidate has macOS Apple Silicon build and limited runtime evidence. The public Basic installer, supported system versions and clean-device installation remain pending. Intel macOS, Windows and Linux have no verified release package. No release date is promised.

现有本机候选有 macOS Apple Silicon 构建及限定运行证据。Basic 公开安装载体、支持系统版本和干净设备首装仍待验证。Intel macOS、Windows 和 Linux 暂无已验证发行包，不承诺发布日期。
